# Codex · 2026-09-14 · PC·휴대폰 조회 대시보드 실행

**주요 파일**: `src/ai_trader/dashboard.py`, `src/ai_trader/web/index.html`,
`pyproject.toml`, `start-dashboard.ps1`, `README.md`

## 배경

사용자가 우선 웹 대시보드로 현재 상태를 확인하도록 요청했다. 기존 대시보드는
모바일 한 열 레이아웃만 있었고, 모든 탭을 순서대로 60초마다 조회하여 첫 화면이
외부 지수·뉴스 응답을 기다렸다. 현재 Python 환경에는 pandas 등 실행 의존성이 없었다.

## 기존 → 변경 후

| 구분 | 기존 | 변경 후 | 변경 이유 |
|---|---|---|---|
| 레이아웃 | PC에서도 최대 560px 한 열 | 900px 이상에서 두 열과 전체 폭 자산 카드, 모바일 한 열 유지 | PC와 휴대폰에서 같은 정보를 읽기 편하게 제공 |
| 갱신 | 모든 탭을 60초마다 순차 조회 | 활성 탭을 10초마다 조회하고 숨겨진 문서에서는 주기 조회 중지 | 현재 보는 화면을 빠르게 갱신하고 불필요한 호출 감소 |
| 첫 화면 | 지수·뉴스 수집이 현황 응답에 포함 | `/api/overview`와 `/api/market` 분리, 기존 `/api/command` 유지 | 외부 데이터 지연이 자산·엔진 현황 표시를 막지 않도록 함 |
| 표시 정확성 | 엔진 정지 중에도 AUTO 표기, 가상 시세와 장부 구분이 약함 | 실제 실행 상태와 가상 시세·자체 장부 안내, 지수의 일봉 기준 표시 | 정지된 매매와 실제 계좌 자산을 잘못 해석하지 않도록 함 |
| 실패 처리 | 실패 시 기존 화면을 오류 한 줄로 교체 | 마지막 조회 결과 유지, 갱신 실패와 재시도 안내 | 연결 단절 시 남아 있는 정보가 최신이 아님을 알림 |
| 조회 전용 | 시작·정지·단발 실행 POST 가능 | `--read-only`에서 세 경로 모두 인증 후 403, 화면 제어 버튼 제거 | 이번 확인용 실행에서 엔진을 조작하지 않도록 함 |
| 실행 준비 | Windows 실행 진입점과 데이터 의존성 선언 부족 | 조회 전용 PowerShell 실행 파일과 pandas·pyarrow·yfinance 선언 추가 | 실행 환경과 재실행 방법을 재현 가능하게 제공 |

## 상세 변경

- 접속 코드가 없는 링크에서는 코드 입력 폼을 표시한다. 조회 API 요청은 기존 지원 헤더인 `X-Dash-Token`을 사용한다.
- 새로고침 중복 요청을 막고, 브라우저로 돌아오면 활성 탭을 다시 조회한다.
- 연결 상태, 마지막 성공 갱신 시각, 빈 기록 안내와 한국어 탭 이름을 추가했다.
- `.venv`에 필요한 데이터 패키지를 설치하고 숨겨진 Python 프로세스로 포트 8765의 LAN 대시보드를 실행했다.
- 토스 인증 키 제공과 외부 서버 배포는 아직 진행하지 않았다.

## 영향 및 호환성

- DB·장부·거래 기록 형식과 기존 환경변수는 변경하지 않았다. 실주문 설정도 변경하지 않았다.
- 조회 API 두 개와 선택 CLI 옵션이 추가되었다. 기존 `/api/command` 응답 필드는 유지되며 guardrails에 `read_only`가 추가되었다.
- `start-dashboard.ps1`은 항상 `--lan --read-only`로 실행한다. 기존 직접 실행 명령은 엔진 제어 기능을 유지한다.
- 10초는 화면 조회 간격이다. 지수는 300초, 뉴스는 600초, 관심 종목 분석은 120초 서버 캐시를 사용한다.
- PC와 서버 프로세스가 실행 중이어야 접속할 수 있다. 휴대폰은 같은 네트워크가 필요하고 방화벽 설정에 따라 접속 허용이 필요할 수 있다.

## 확인

- 실제 HTTP: 무인증 `/api/overview` 401, 인증 요청 200, 가상 시세와 조회 전용 상태 확인. 현황 응답 약 0.02초.
- 실제 HTTP: 조회 전용 서버의 인증된 `/api/engine/start`, `/api/engine/stop`, `/api/engine/once` 모두 403.
- 로컬 Chrome 자동 검증: 1440px PC, 390px·360px 휴대폰 폭에서 네 개 탭, 가로 넘침 없음, 새로고침·10초 자동 갱신·연결 실패 후 복구·접속 코드 폼 통과. JavaScript 오류 0개.
- PC·휴대폰 스크린샷을 생성하고 직접 확인했다. 앱 내 브라우저는 사용 가능한 연결이 없어 로컬 Chrome으로 검증했다.
- `python -m compileall -q src/ai_trader/dashboard.py` 통과. `git diff --check` 통과.
- 같은 PC에서 LAN 주소로 HTTP 200 확인. 실제 휴대폰 기기 접속은 확인하지 않음.
- 외부 Yahoo 지수 요청은 실행 환경의 네트워크 연결 실패로 수신하지 못했다. 화면에는 수신 불가가 표시된다. 토스 인증·실제 계좌 조회는 키가 없어 확인하지 않음.

# Codex · 2026-09-14 · 토스 실연결 검증 및 시세 응답 수정

**주요 파일**: `src/ai_trader/config.py`, `src/ai_trader/data.py`, `tests/test_toss_feed.py`

## 배경

사용자가 로컬 `.env`에 토스 ID와 시크릿을 입력했다. 공식 서버 인증과 계좌·보유 자산 조회는
성공했지만 기존 코드는 계좌 식별자가 없으면 키 미설정으로 처리했다. 현재가 응답의
`lastPrice`를 읽지 못했고, 일봉 조회는 잘못된 `symbols` 파라미터로 HTTP 400을 반환했다.

## 기존 → 변경 후

| 구분 | 기존 | 변경 후 | 변경 이유 |
|---|---|---|---|
| 인증 준비 판정 | ID·시크릿·계좌 식별자 모두 필요 | ID·시크릿만 필요, 기존 계좌 자동 조회 사용 | 시세는 계좌 헤더 없이 조회할 수 있고 계좌 식별자는 API에서 확인 가능 |
| 현재가 | `close`·`price`만 읽어 정상 응답도 0으로 처리 | 공식 `lastPrice`를 우선 파싱 | 토스 실제 응답의 현재가를 반영 |
| 일봉 요청 | `symbols`를 전달 | 단일 `symbol` 전달, 1회 조회는 최대 200봉 | 공식 요청 계약을 준수해 400 오류 해결 |
| 일봉 응답 | `result`를 곧바로 목록으로 처리 | `result.candles`를 읽고 날짜 오름차순 변환 | 페이지 응답 구조에 맞춰 기술지표에 필요한 OHLCV 생성 |
| AI 키 상태 | 예시 `sk-ant-...`도 설정 완료로 판정 | 예시값은 미설정으로 판정 | 실제 AI 키를 입력하지 않은 상태를 화면에서 명확하게 표시 |
| 실행 서버 | 키 입력 전 프로세스에서 가상 시세 사용 | 키를 로드해 실제 토스 피드 사용, 기존 접속 코드와 조회 전용 유지 | 사용자가 기존 링크에서 실제 시세를 확인하도록 반영 |

## 상세 변경

- 공식 `https://openapi.tossinvest.com/openapi-docs/latest/openapi.json`의 요청·응답 구조와 실제 응답을 확인했다.
- 인증 키·액세스 토큰·계좌번호·잔고 값은 검증 출력이나 이 기록에 남기지 않았다.
- 계좌 목록은 초당 1회 제한이 있어 중복 검증 요청 간 1.1초 간격을 두었다.
- 일반 실행 환경에서 외부 연결이 차단되어 승인된 네트워크 제한 밖의 조회 전용 실행으로 검증하고 서버를 재시작했다.

## 영향 및 호환성

- `.env`의 사용자 키와 실주문 스위치를 수정하지 않았다. 실제 주문은 호출하지 않았다.
- `TOSS_ACCOUNT`는 한 계좌의 현재 연결에서 추가 설정이 필요하지 않았다. 여러 계좌가 있는 경우는 이번 실연결 검증 대상이 아니다.
- DB·자체 장부·주문 기록 형식은 변경하지 않았다. 대시보드의 자산 카드는 여전히 자체 장부 기준이며 토스 계좌 잔고를 표시하도록 변경한 것은 아니다.
- AI 분석용 키는 예시값이고 anthropic·mlflow 패키지는 설치되지 않은 상태다. 현재 시세·계좌 조회와 웹 확인에는 필요하지 않다.

## 확인

- 토스 인증 HTTP 200, 계좌 목록 HTTP 200, 계좌 1개 확인, 계좌 자동 선택 성공.
- 실제 클라이언트의 보유 자산·매수 가능 금액 조회 성공. 민감한 금액과 계좌 정보는 출력하지 않음.
- 현재가 3종목 모두 양수, 삼성전자 일봉 60개 정상 수신.
- 대시보드 `/api/overview`, `/api/radar`, `/api/control` HTTP 200. 관심 종목 20개 가격·분석 점수 모두 확인.
- 모바일 크기의 Chrome에서 토스 연결 표시, 가상 시세 배너 해제, 관심 종목 행 표시, JavaScript 오류 없음 확인.
- 예시 AI 키 수정 후 서버를 재시작하고 `source=toss`, `read_only=true`, `has_llm_key=false` 확인.
- `python -m unittest discover -s tests -v`: 회귀 테스트 5개 통과. 외부 API 호출 없이 인증 조건·실제 응답 구조·일봉 정렬·빈 페이지·요청 제한·예시 키 상태 검증.
